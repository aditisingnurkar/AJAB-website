Create a UI/UX wireframe and interactive prototype for my existing café website called "AJAB".

AJAB is a modern café with a warm BEIGE visual theme.

IMPORTANT:
This is an accessibility and inclusive-design project. I already have a common AJAB café website. Do NOT replace the café concept with a generic accessibility website.

The website must retain the core café functionality while providing three accessible versions for different user groups:

1. COMMON MAIN WEBSITE
2. ELDERLY USERS
3. RURAL USERS – MULTILINGUAL
4. VISUALLY IMPAIRED USERS

The prototype should demonstrate how the SAME café services and features are adapted for each user group.

VERSION 1 — ELDERLY USERS
==================================================

Create an elderly-friendly version of AJAB.

Do NOT remove the café's functionality.

Adapt the interface using:

- Larger text
- Larger buttons
- Large touch targets
- High readability
- Simple navigation
- Fewer options visible at once
- Clear labels instead of icon-only controls
- Strong contrast
- Simple and familiar terminology
- Clear confirmation messages
- Simple ordering flow

Add an "Elderly Friendly Mode" toggle in Accessibility Settings.

Example:

TEXT SIZE
[ Normal ] [ Large ] [ Extra Large ]

CONTRAST
[ Standard ] [ High Contrast ]

SIMPLIFIED NAVIGATION
[ ON ]

Keep the navigation extremely clear:

HOME | MENU | ORDER | RESERVE

Do not use complicated menus.

For food items, show:
- Large food image
- Food name
- Price
- Nutrition
- Add button

For reservation:
- Large date selector
- Large time buttons
- Large + / – controls
- Very clear confirmation screen

VERSION 3 — VISUALLY IMPAIRED / LOW VISION USERS
==================================================

Create an accessibility-focused version of AJAB for visually impaired and low-vision users.

IMPORTANT:
Do not rely only on colour or visual images to communicate information.

Include:

- Large readable typography
- High contrast
- Clear text hierarchy
- Large buttons
- Text labels with icons
- Strong focus states
- Descriptive labels
- Alt-text placeholders for food images
- Screen-reader-friendly content structure
- Minimal decorative elements

Add an accessibility panel:

TEXT SIZE
[ Normal ] [ Large ] [ Extra Large ]

CONTRAST
[ Standard ] [ High Contrast ]

SCREEN READER MODE
[ ON ]

IMAGE DESCRIPTIONS
[ ON ]

For every important image, provide descriptive text.

Example:

Image description:
"Hot cappuccino served in a white ceramic cup."

For menu items, ensure all important information is available as text:

Cappuccino
₹150
120 kcal
Contains milk
[ Add to Cart ]

Do not communicate important information through colour alone.

For table availability:

Available
Reserved
Occupied

Use text labels along with visual indicators.

DESIGN STYLE
==================================================

Maintain AJAB's existing identity.

Theme:
- Beige background
- Dark brown/black text
- Warm café aesthetic
- Minimal and clean
- Consistent branding

However, accessibility versions should prioritize usability over decoration.

Use:
- Clear spacing
- Strong hierarchy
- Large clickable areas
- Consistent navigation
- Simple labels

Do not add:
- AI
- Chatbot
- Voice assistant
- Unnecessary animations
- Unrelated features
