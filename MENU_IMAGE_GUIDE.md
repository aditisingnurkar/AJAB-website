# AJAB Menu Image Guide

This guide tracks the manual upload of 44 food photographs for the AJAB European Bakery & Beanery menu.

## Image Specifications
- **Preferred format:** WebP (JPG, JPEG, PNG also supported).
- **Recommended aspect ratio:** 4:3.
- **Recommended resolution:** at least 1200 × 900 pixels.
- **Guidelines:** Food should be clearly visible and centred. Consistent lighting and professional food photography. Avoid watermarks, text embedded in images, and unrelated food. Keep file sizes reasonable for fast page loading.

## How to Update Status
When you upload an image to the correct folder, change the `[MISSING]` status below to `[UPLOADED]`.

You can also run the built-in image validator to check for missing images:
```bash
npm run check-images
```
